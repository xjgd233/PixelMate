# PixelMate 1.0.1 发布说明

发布日期：2026-11-08

目标平台：Windows x64

## 本次更新

- 批注编辑器改为跟随图片中的点击位置出现，不再固定挡住画面中央。
- 编辑器接近窗口边缘时会自动翻转到另一侧，并保持在可视区域内。
- 缩小编辑器尺寸，保留多行输入、字体颜色、快捷色块和快捷键操作。
- README 新增像素测量、放大镜、批注编辑器和设置界面的真实截图。
- Windows 离线包同时携带 README 截图与更新后的发布说明。

## 下载

推荐下载：

```text
PixelMate-1.0.1-win-x64-offline.zip
```

完整解压后运行 `START-PIXELMATE.cmd` 或 `PixelMate.exe`。该包为 Windows x64
自包含版本，不需要额外安装 .NET Runtime。

## 验证状态

- Release 构建 0 警告、0 错误。
- 105 项自动化测试全部通过。
- macOS 真实窗口已验证批注编辑器在画布中部、左上和右下位置的定位；边缘自动翻转
  正常，批注保存和撤销正常。
- Windows x64 包由 macOS 交叉发布，并检查主程序与图形原生依赖架构。1.0.1 的
  批注定位改动尚未重新进行 Windows 实机回归；核心功能沿用已在 1.0.0 完成实机验收
  的实现。

## 已知限制

- Windows 包仍未进行 Authenticode 代码签名，SmartScreen 或智能应用控制可能提示
  未知发布者。
- 单张图片限制为边长不超过 `32767` 像素、总像素不超过 `6400` 万。
- 批注仅保存在当前会话中，不修改源图片。
- Windows 自包含包约 `136 MB`，主要来自 .NET 运行时、图形原生库与内置中文字体。
