# PixelMate 1.0.0 发布说明

发布日期：2026-11-04

目标平台：Windows x64

## 交付内容

- Windows x64 自包含发布目录，无需另装 .NET Runtime。
- 应用名称、产品名称、文件版本和产品版本均为 PixelMate `1.0.0`。
- Windows 可执行文件已嵌入 PixelMate 应用图标。
- 顶部工具栏、深色画布和底部状态栏。
- PNG、JPG、JPEG、BMP、WebP 图片浏览。
- 滚轮缩放、中键拖动平移和空格临时抓手。
- 多条像素距离测量、方向锁定、复制与清除。
- 原始像素取色、透明通道保留和 HEX/RGB 复制。
- 像素网格放大镜及三档倍率。

## 快捷键

| 操作 | macOS | Windows |
| --- | --- | --- |
| 打开图片 | `⌘O` | `Ctrl+O` |
| 测量工具 | `M` | `M` |
| 取色工具 | `I` | `I` |
| 放大镜工具 | `Z` | `Z` |
| 临时抓手 | 按住空格拖动 | 按住空格拖动 |
| 放大 / 缩小 | `⌘+` / `⌘-` | `Ctrl++` / `Ctrl+-` |
| 适应窗口 | `⌘0` | `Ctrl+0` |
| 100% 原始尺寸 | `⌘1` | `Ctrl+1` |
| 复制当前结果 | `⌘C` | `Ctrl+C` |
| 放大镜降低 / 提高倍率 | `[` / `]` | `[` / `]` |
| 清除全部测量 | `⌫` | `Delete` |

测量时按住 `Shift` 可锁定水平或垂直方向。

## 验证状态

macOS ARM64：

- Debug 与 Release 构建通过。
- 72 项自动化测试通过。
- 已通过真实窗口快捷键、测量、取色、放大镜、缩放与平移测试。

Windows x64：

- 已从 macOS 成功交叉发布自包含目录。
- 已检查主程序、.NET 运行时及 Skia、HarfBuzz、OpenGL 原生依赖均为 x86-64 PE。
- 仍待真实 Windows 环境完成启动、文件选择器、剪贴板、WebP 解码、透明 PNG、高 DPI 和快捷键验证。

## 已知限制

- 单张图片边长限制为 `32767` 像素，总像素限制为 `6400` 万。
- Windows 自包含发布目录约 `106 MB`，主要来自 .NET 运行时和图形原生库；本轮未启用有兼容风险的裁剪。
- 不修改源图片，不上传图片。
