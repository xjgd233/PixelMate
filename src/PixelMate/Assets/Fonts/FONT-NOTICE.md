# Bundled font

PixelMate bundles the following static Noto Sans CJK SC font files so that
Chinese and Latin text use one complete glyph family on every supported
platform:

- `NotoSansCJKsc-Regular.otf`
- `NotoSansCJKsc-Bold.otf`

Source: <https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese>
